# Kamel Guemmour — Developer Portfolio

A bilingual English/French portfolio website for showcasing web development services and personal projects.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. GitHub will provide the published site URL once deployment completes.
